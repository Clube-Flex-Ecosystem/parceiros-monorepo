# Parceiros Clube Flex

O Parceiros Clube Flex é o catálogo oficial de benefícios do Clube Flex. Ele reúne os parceiros participantes em um único lugar para que suas informações, condições e descontos estejam sempre atualizados e fáceis de consultar.

## O que o produto entrega

- Um painel exclusivo para a equipe responsável cadastrar e manter os parceiros.
- Um catálogo público para encontrar parceiros disponíveis.
- Uma página de detalhes para cada parceiro, com informações de contato, atendimento, condições e descontos.
- Descontos apresentados de acordo com cada plano do Clube Flex.

## Como funciona

1. A equipe do Clube Flex cadastra ou atualiza um parceiro.
2. Quando o cadastro está pronto, ele é publicado no catálogo.
3. Pessoas interessadas consultam os parceiros publicados e conhecem as condições e descontos de cada plano.

## Informações disponíveis ao público

Cada parceiro publicado pode apresentar sua categoria, descrição, endereço opcional, formas de contato, site, instruções e descontos percentuais correspondentes aos planos do Clube Flex.
