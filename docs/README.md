# Documentação — CMS de parceiros Clube Flex

Esta pasta contém as especificações consolidadas da entrega final do CMS de parceiros Clube Flex.

## Estrutura

- [Visão geral](specs/overview.md): contexto do produto, atores, fluxo principal, capacidades e critério de validação.
- [Domínio](specs/domain.md): entidades, relacionamentos, regras de negócio, casos de uso e estados do parceiro.
- [API](specs/api.md): autenticação por sessão, rotas administrativas e públicas, além dos contratos de dados.

## Leitura recomendada

1. Comece pela visão geral para entender o objetivo e o escopo do produto.
2. Consulte o domínio para implementar as regras e o modelo de dados.
3. Use a API como contrato entre o painel administrativo, o catálogo público e o servidor.
